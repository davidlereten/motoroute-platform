# MotoRoute Platform Web App v0.2

Bu paket Supabase üzerinde kurulan MotoRoute DB ile çalışan Next.js frontend demosunun v0.2 sürümüdür.

## v0.2 farkları

- Daha profesyonel ana sayfa hero alanı
- Daha temiz marka kartları
- Araç katalog sonuç kartları iyileştirildi
- Tamirci/parçacı arama alanı düzenlendi
- Genel arama kartları daha okunabilir hale getirildi
- Mobil/responsive CSS iyileştirildi
- Vercel/Next.js uyumlu proje yapısı korunur

## Vercel Environment Variables

Vercel → Project → Environment Variables:

```env
NEXT_PUBLIC_SUPABASE_URL=https://...supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_...
```

Secret key kullanmayın.
